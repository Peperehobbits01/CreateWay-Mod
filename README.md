# CreateWay-Mod
The CreateWay mod is helping with seamless integration between mods inside the Creatway modpack and adds some usefull extra features for SMP's using the modpack to play.

On multiplayer servers, players can open the vote screen from the **Vote** button beside their survival or creative inventory and select up to 64 dates at least seven days in the future on the calendar. Single-player worlds do not use the vote system. A date needs votes from at least four distinct players and at least 75% of players who logged in during the previous seven days before the vote ends. An operator can then set the opening time with `/setendhour HH:mm`. Operators can use `/reopenvotes` to restart a completed poll; this clears the previous result and all votes while keeping player login history.

When More Babies is installed, an optional compatibility mixin uses the structure-generation random source for its Elder Guardian baby roll, avoiding cross-thread random access during C2ME chunk generation. More Babies is not required by this mod.
