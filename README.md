# CreateWay-Mod
The CreateWay mod is helping with seamless integration between mods inside the CreatWay modpack and adds some usefull extra features for SMP's using the modpack to play.

On multiplayer servers, players can open the vote screen from the Eye of Ender button beside the recipe book in the survival inventory. Each ballot can include up to five dates between seven days and two months from today. Single-player worlds do not use the vote system. A date needs votes from at least four distinct players and at least 75% of players who logged in during the previous seven days before the vote ends. Operators joining after the vote completes are prompted in a title to set the opening time with `/setendhour HH:mm`. Players online when the scheduled time arrives receive a title and advancement challenge-complete sound; later joiners also see the scheduled date and time in a title. Operators can use `/reopenvotes` to restart a completed poll; this clears the previous result and all votes while keeping player login history.

The server config is stored in `config/createwaymod-server.toml`. `disableAdvancementAnnouncements` defaults to `true`, disabling advancement chat announcements by default in new worlds; existing worlds retain their saved gamerule setting. `enableVoteSystem` defaults to `true` and can be set to `false` to disable the vote screen, voting, and vote commands. Restart the server after changing either option.

Operators can use `/createway debug end open`, `/createway debug end closed`, and `/createway debug end normal` to test portal-eye locking without changing vote data. To test the scheduled opening and `/setendhour`, use `/createway debug vote complete` to create a test vote for today, then set a future time with `/setendhour HH:mm`; use `/reopenvotes` to clear the test vote. The End debug override resets when the server stops. End Remastered is included as a development runtime dependency so its custom eyes can be tested; its eye placement on vanilla portal frames follows the same lock.

When More Babies is installed, an optional compatibility mixin uses the structure-generation random source for its Elder Guardian baby roll, avoiding cross-thread random access during C2ME chunk generation. More Babies is not required by this mod.
